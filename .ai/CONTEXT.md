# Web of Thoughts project context

## Mission

Specify and test a typed, budgeted network of candidate thoughts with explicit relations, challenge, synthesis, pruning, and stopping rules.

## Source map

- Human entry: `START_HERE.txt`
- Definition, protocol, and evaluation: `docs/`
- Modular prompts: `prompts/`
- Run records: `experiments/`
- Machine validation: `schemas/run.schema.json`

## Invariants

This is an unproven experimental method. Do not record private hidden reasoning. Compare with strong budget-matched baselines. Preserve concise rationale, evidence, budgets, outcomes, failures, and uncertainty.
