HUMAN WORK
----------

Use docs/ for the method and evaluation design, experiments/ for run records, and
prompts/ for technical prompt components. Markdown documents render directly in
Codex/GitHub; formal reports can be exported to DOCX or PDF when needed.

Do not record private hidden model reasoning. Preserve concise rationale, evidence,
decisions, budgets, results, failures, and uncertainty.

AI-agent instructions and memory are in AGENTS.md and .ai/.
