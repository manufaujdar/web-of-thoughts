# Documentation index

Web of Thoughts is an experimental, typed, budget-aware graph reasoning
framework. It is a falsifiable research proposal and specification, not a
claim of superiority over direct prompting, chains, or trees.

## Authoritative documents

- README.md: hypothesis, repository map, quick start, and principles.
- docs/00-concept.md through docs/05-roadmap.md: concept, formal model, protocol, research context, evaluation, and roadmap.
- docs/glossary.md: stable terminology.
- docs/architecture.md and docs/technical-overview.md: software/artifact baseline.
- prompts/, schemas/run.schema.json, and experiments/: experiment contracts.
- AGENTS.md, .ai/, and .agents/skills/: experiment design and audit rules.
