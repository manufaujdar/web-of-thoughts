## Release boundary

Web of Thoughts is an experimental Apache-2.0 research framework. It does not
prove superiority over direct, chain, or tree baselines; it must not collect
private hidden chain-of-thought; and it must not be described as a hosted,
clinical, or production reasoning service without a separate review.
